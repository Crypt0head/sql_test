Оценка сроков: расчет commission_monthly (Стандарт / Акционный)
===============================================================

Цель:
Заменить текущую некорректную подтяжку commission_monthly из Озера
на расчет по бизнес-правилам.

Что делаем:
- Реализуем расчет commission_monthly для тарифов:
  1) Стандарт: оборот прошлого месяца / число терминалов + MCC-группа + диапазон + фикс.
  2) Акционный: аналогично, с отдельным правилом списания фиксированной комиссии
     при отсутствии движения.
- Встраиваем расчет в текущий поток формирования витрины.

Оценка трудозатрат:
- Рабочая версия: 56-72 ч
- Рекомендуемый план для согласования: 64 ч + 20% буфер = 77 ч
- PoC (черновик): 28-40 ч

Основные риски:
- незафиксированные правила по MCC/диапазонам;
- неоднозначность правила "нет движения" для акционников;
- кейсы с несколькими MCC/терминалами у клиента;
- качество входных данных.

Что нужно утвердить до старта:
1) финальную матрицу ставок (MCC + диапазоны + фикс),
2) формальное правило для акционников ("нет движения"),
3) набор контрольных кейсов для сверки.

План-график (1 специалист):
- Дни 1-2: фиксация правил и тест-контур
- Дни 3-5: реализация "Стандарт"
- Дни 6-7: реализация "Акционный"
- Дни 8-9: интеграция и сверка
- День 10: финализация и передача
