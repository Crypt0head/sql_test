Таблица: «Распределение клиентов по сегментам ЧОД ТЭ»
Dataset: sbx_da.vd_chod_clients_by_month
Клиент = ИНН (не agr_id / договор)

Перед копированием метрик:
1) SQL датасета = sources/sql/vd_chod_clients_by_month.sql
2) Save → Sync columns (есть kedr_obshiy_chod, kedr_obshiy_chod_contrib)
3) Dimension в chart: client_bucket (или «Категория клиентов»)
4) Native filter Месяц → report_month
5) Убрать метрики на total_chod_placeholder


==============================================================================
Dimension
==============================================================================
client_bucket


==============================================================================
1) Количество, шт.  (клиенты = уникальные ИНН в когорте ЧОД ТЭ)
==============================================================================
COUNT(DISTINCT CASE
  WHEN NULLIF(BTRIM(CAST(inn AS TEXT)), '') IS NOT NULL
  THEN NULLIF(BTRIM(CAST(inn AS TEXT)), '')
END)


==============================================================================
2) Сумма, руб  (ЧОД ТЭ acquiring)
==============================================================================
SUM(COALESCE(CAST(NULLIF(BTRIM(CAST(chod_sum AS TEXT)), '') AS NUMERIC), 0))


==============================================================================
3) Количество клиентов с отрицательным ЧОД общий
   (ИНН с Общим ЧОД Kedr < 0 внутри когорты)
==============================================================================
COUNT(DISTINCT CASE
  WHEN NULLIF(BTRIM(CAST(inn AS TEXT)), '') IS NOT NULL
   AND COALESCE(CAST(NULLIF(BTRIM(CAST(kedr_obshiy_chod AS TEXT)), '') AS NUMERIC), 0) < 0
  THEN NULLIF(BTRIM(CAST(inn AS TEXT)), '')
END)


==============================================================================
Важно
==============================================================================
- Сегмент (+ / 0 / −) строится по ЧОД ТЭ (chod_sum), не по Общему ЧОД.
- Если у одного ИНН несколько договоров с разными знаками ЧОД ТЭ,
  ИНН может попасть в разные строки (grain vd = agr × month).
  Для строго «1 ИНН = 1 когорта» нужна пересборка vd на grain inn×month.
  Сейчас считаем DISTINCT inn внутри уже выбранной строки client_bucket.
- Не использовать SUM(kedr_obshiy_chod) и total_chod_placeholder.
