Dataset: sbx_da.tmp_shestopalov_acq_datamart_q1_v3
Набор ниже сделан так, чтобы карточки сходились в 0:
- клиенты: positive + negative = total
- терминалы: active + inactive = total

1) Клиенты всего
COUNT(
  DISTINCT CASE
    WHEN NULLIF(TRIM(agr_id), '') IS NOT NULL
    THEN TRIM(agr_id)
    ELSE NULL
  END
)

2) Клиенты с положительным ФР
COUNT(
  DISTINCT CASE
    WHEN COALESCE(CAST(NULLIF(BTRIM(CAST(fin_result_num AS TEXT)), '') AS NUMERIC), 0) > 0
         AND NULLIF(TRIM(agr_id), '') IS NOT NULL
    THEN TRIM(agr_id)
    ELSE NULL
  END
)

3) Клиенты с отрицательным/нулевым ФР (аддитивно: всего - положительные)
COUNT(
  DISTINCT CASE
    WHEN NULLIF(TRIM(agr_id), '') IS NOT NULL
    THEN TRIM(agr_id)
    ELSE NULL
  END
)
-
COUNT(
  DISTINCT CASE
    WHEN COALESCE(CAST(NULLIF(BTRIM(CAST(fin_result_num AS TEXT)), '') AS NUMERIC), 0) > 0
         AND NULLIF(TRIM(agr_id), '') IS NOT NULL
    THEN TRIM(agr_id)
    ELSE NULL
  END
)

4) ФР итог
SUM(COALESCE(CAST(NULLIF(BTRIM(CAST(fin_result_num AS TEXT)), '') AS NUMERIC), 0))

5) ФР положительный
SUM(
  CASE
    WHEN COALESCE(CAST(NULLIF(BTRIM(CAST(fin_result_num AS TEXT)), '') AS NUMERIC), 0) > 0
    THEN COALESCE(CAST(NULLIF(BTRIM(CAST(fin_result_num AS TEXT)), '') AS NUMERIC), 0)
    ELSE 0
  END
)

6) ФР отрицательный (включая 0)
SUM(
  CASE
    WHEN COALESCE(CAST(NULLIF(BTRIM(CAST(fin_result_num AS TEXT)), '') AS NUMERIC), 0) <= 0
    THEN COALESCE(CAST(NULLIF(BTRIM(CAST(fin_result_num AS TEXT)), '') AS NUMERIC), 0)
    ELSE 0
  END
)

7) Терминалы всего
SUM(COALESCE(CAST(NULLIF(BTRIM(CAST(term_cnt AS TEXT)), '') AS NUMERIC), 0))

8) Терминалы активные
SUM(COALESCE(CAST(NULLIF(BTRIM(CAST(active_terms AS TEXT)), '') AS NUMERIC), 0))

9) Терминалы неактивные (аддитивно: всего - активные)
COALESCE(SUM(CAST(NULLIF(BTRIM(CAST(term_cnt AS TEXT)), '') AS NUMERIC)), 0)
-
COALESCE(SUM(CAST(NULLIF(BTRIM(CAST(active_terms AS TEXT)), '') AS NUMERIC)), 0)
