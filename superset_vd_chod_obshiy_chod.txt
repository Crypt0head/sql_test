Таблица: «Распределение клиентов по сегментам ЧОД ТЭ»
Dataset: sbx_da.vd_chod_clients_by_month

------------------------------------------------------------------------------
1) Обновить SQL датасета
------------------------------------------------------------------------------
Data → Datasets → vd_chod_clients_by_month → Edit SQL
Вставить целиком: sources/sql/vd_chod_clients_by_month.sql
Save → Sync columns

Должны появиться колонки:
  kedr_obshiy_chod
  kedr_obshiy_chod_contrib

Убрать из chart метрику на total_chod_placeholder (всегда NULL → N/A).


------------------------------------------------------------------------------
2) Метрики chart (Aggregate)
------------------------------------------------------------------------------
Dimension:
  Категория клиентов / client_bucket

Количество, шт.
COUNT(DISTINCT agr_id_key)
-- или COUNT(*) если grain уже 1 клиент × месяц

Сумма, руб  (ЧОД ТЭ acquiring)
SUM(chod_sum)

Общий ЧОД  (Kedr)
SUM(COALESCE(CAST(NULLIF(BTRIM(CAST(kedr_obshiy_chod_contrib AS TEXT)), '') AS NUMERIC), 0))
-- Custom label: Общий ЧОД
-- НЕ использовать SUM(kedr_obshiy_chod) — задвоит по agr внутри ИНН
-- НЕ использовать MAX(total_chod_placeholder)


------------------------------------------------------------------------------
3) Фильтр
------------------------------------------------------------------------------
Native «Месяц» → report_month (один месяц).
Убрать мёртвый Filters: snapshot_month_start, если колонки нет в vd.


------------------------------------------------------------------------------
4) Смысл колонок
------------------------------------------------------------------------------
chod_sum                 — ЧОД ТЭ (эквайринг), сегменты +/−/0 по нему
kedr_obshiy_chod_contrib — Общий ЧОД Kedr, один раз на inn×month → SUM в итогах
kedr_obshiy_chod         — то же значение на строках; для SUM в этой таблице не брать
